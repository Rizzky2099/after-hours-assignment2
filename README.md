# After Hours — Assignment 2

Music-video player for RMIT OART1013 Interactive Media 1.

## Features
Play/pause, replay, timeline seeking, elapsed/total time, mute, volume and Cinema mode. Cinema mode expands the player and dims surrounding content; Escape exits. Controls support keyboard navigation and the layout adapts to narrow screens. No external JavaScript or CSS libraries are used beyond the supplied CSS reset.
